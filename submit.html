QUESTIONS & VERIFICATION

إرسال سؤال أو طلب تحقق

يمكنك إرسال سؤال عام أو طلب مراجعة دواء غير مدرج. لا ترسل معلومات شخصية أو تفاصيل علاجية حساسة.

?

أسئلة المرضى والصيادلة

أرسل سؤالاً عاماً عن السواغات أو اطلب توضيحاً حول كيفية قراءة التصنيف. يراجع فريق البحث السؤال قبل نشر أي إجابة.

▧

إرسال صورة دواء

يمكن للصيدلي إرسال صورة واضحة للنشرة أو العبوة التي تظهر قائمة المكونات واسم المنتج والتركيز والشكل الصيدلاني.

✓

اعتماد المعلومات

لا تُعرض الصور أو الإجابات تلقائياً للعامة. يتأكد المسؤول من المصدر والصياغة قبل تحديث قاعدة البيانات.

كيف تتم مراجعة الطلبات؟

ترسل السؤال أو صورة العبوة/النشرة عبر النموذج.
يراجع فريق البحث المعلومات ومصدرها.
لا تُضاف أي معلومة إلى قاعدة البيانات إلا بعد التحقق والموافقة.

فتح نموذج الإرسال

سيضاف رابط النموذج بعد إعداده.

تنبيه طبي وخصوصية

لا تستخدم هذا النموذج لحالات الطوارئ أو لاتخاذ قرار بإيقاف دواء. لا ترفع صوراً تحتوي على اسم المريض أو بياناته أو وصفاته الشخصية. رفع الصور عبر Google Forms يتطلب عادةً تسجيل الدخول بحساب Google؛ يجب إبلاغ المستخدم بذلك قبل الإرسال.
